## 1. About the Project

Student College Budget Tracker is a simple Python console-based project designed to help college students keep track of their income and expenses.

A student may receive money from different sources such as pocket money, scholarship and job income. At the same time, money may be spent on food, books, travel, mobile services, entertainment and other requirements.

This project takes these values as input and calculates the total income, total expenses and final balance.

The project also gives simple suggestions based on spending and provides an option to save the financial record in a text file.

---

## 2. Main Features

- Enter student name, course and year
- Enter pocket money
- Enter scholarship amount
- Enter job income
- Calculate total income
- Enter different types of expenses
- Add an extra expense
- Calculate total expenses
- Calculate remaining balance
- Display savings or loss
- Give basic spending suggestions
- Save the record in a text file
